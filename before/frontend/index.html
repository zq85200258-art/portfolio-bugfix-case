        Demo notes How to observe same-origin and cross-origin behavior

        1. Same-origin (http://127.0.0.1:8000)

        Open the portal directly from the FastAPI server with API base set to same-origin. Submit the demo credentials and watch the follow-up session check: in the BEFORE state, POST /api/login returns 200, yet the immediate GET /api/me returns 401 and the portal stays signed out.

        2. Cross-origin (5500 → 8000)

        Serve this frontend/ folder on port 5500 and point the API base URL below (or via ?api=http://127.0.0.1:8000) to port 8000. Because requests use JSON headers and credentials: 'include', the browser sends a preflight request before sign-in and surfaces CORS rejections in the status panel and Network tab.

        Tip: You can also preset the target before page load via window.LUMENDESK_API or the ?api= query parameter.
